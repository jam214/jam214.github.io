How I Set Up My Cybersecurity Portfolio

Posted on May 1, 2025

When I first started building my cybersecurity portfolio, I knew I needed more than just a resume to stand out. I wanted a space to showcase real skills, tools I’ve worked with, and the projects that reflect my growth. So I began by purchasing a personal domain — jsancyber.website — which gave me a professional identity online. I connected this domain to a GitHub Pages site, where I built a simple HTML portfolio that includes my bio, contact info, and links to my GitHub and LinkedIn profiles. The next step was uploading sample projects to GitHub — including Python scripts, network scans, and basic forensics analysis — each with a README.md file that explains the project’s goal and how it works. I also created a branded email address to use for professional contacts and outreach. One of the most valuable parts of this process was learning how DNS, CNAME, A records, and SSL certificates work — things I’d only read about in class. By doing it myself, I not only built a live portfolio, but also picked up real-world networking and hosting skills along the way. This portfolio is still growing, but it’s already helped me feel more confident when applying for internships and talking to others in the cybersecurity field. If you’re starting out, don’t wait — create a space that shows what you can do. It’s worth the time.
